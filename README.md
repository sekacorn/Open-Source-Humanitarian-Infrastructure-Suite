# Open-Source Humanitarian Infrastructure Suite

A collection of free, open-source humanitarian software tools for NGOs, researchers, universities, civic technologists, and community organizations working on food security, water access, energy equity, climate health, disaster resilience, education research, and crisis coordination.

## Mission

This suite is designed to provide public-interest organizations with inspectable, forkable, self-hostable software foundations for humanitarian and civic technology work.
